# Code of Conduct

We want people with different backgrounds and levels of experience to be able to contribute to dead-assets.

## Expected behavior

Be respectful, patient, and specific. Critique code and ideas without attacking people. Accept constructive feedback, acknowledge mistakes, respect privacy, and help keep discussions focused on the project.

Harassment, discriminatory remarks, threats, sexualized attention, publishing private information without consent, and repeated disruptive behavior are not acceptable. These expectations apply to project issues, pull requests, discussions, and other spaces where someone represents this project.

## Reporting and enforcement

Report inappropriate public content with GitHub's reporting tools. For a confidential project report, contact the repository owner through a private contact method listed on their GitHub profile. If none is listed, request a private channel without posting sensitive details. If the owner is involved or cannot be contacted, use [GitHub's abuse reporting process](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

Maintainers may remove or edit content, request a change in behavior, restrict participation, or ban a participant based on the severity and repetition of the conduct. Reports should be handled discreetly, sharing information only as needed to address the concern. Maintainers are also expected to follow this policy.
